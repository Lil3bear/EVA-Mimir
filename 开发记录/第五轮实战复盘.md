## 本轮新增优化（vs 第四轮）

### 架构层

1. **靶场健康检查**（优化 A）：`start_challenge` 后用 curl 探测目标，最多 5 次×10s，不可达则 close 释放槽位，5 分钟后自动重新入队
2. **环境重试守护线程**：`_env_retry_feeder` 每 30s 检查重试队列，到期的题放回工作队列
3. **调度优先级评分函数**（优化 C）：按难度权重 + 题型权重 + 部分进展加分排序
4. **hard 题强制停止**（优化 D）：50 轮无 flag 强制停止（hard），80 轮无 flag 强制停止（any），释放 Solver 给其他题

### Agent 能力层

5. **渗透阶段状态机**：4 阶段（RECON→INITIAL_ACCESS→POST_EXPLOIT→DATA_EXFIL），自动检测阶段切换并注入标准动作
6. **攻击向量级循环检测**：连续 8 轮同一攻击向量（LFI/SQLi/...）→ 直接纠偏 + 触发 Observer 审查
7. **Observer 未利用情报自动关联**：扫描 memory 中的 IP/密码/路径等关键词，与最近 N 轮工具调用交叉检查，未使用则强制发 `send_correction`
8. **bash 超时按命令类型区分**：python/sage → 300s，gcc/make → 180s，其他 → 120s；bash 工具新增可选 `timeout` 参数（最大 600s）
9. **多阶段渗透 SKILL 全面重写**：核心原则多 flag 分布说明、拿到 shell 后标准动作序列、凭据收集、内网服务利用、决策树
10. **逆向/对抗 SKILL 增强**：Binary Patching 完整流程、x86 指令字节速查、自动化搜索 patch 点、"禁止手算"强调
