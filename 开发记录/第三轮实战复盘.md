## 本轮新增优化（vs 第二轮）

1. **max_rounds 按难度分级**：easy=30 / medium=60 / hard=100（easy 题从 22min 降到 9min）
2. **并行 3 路**：3 题同时解，总耗时从 4.5h 降到 3h
3. **每 20 轮强制回顾**：注入已知凭据/未探索方向，防止"视而不见"
4. **方向循环检测升级**：path traversal 目标不同时不被视为同一 approach
5. **Kimi 联网搜索**：security_search 接入 moonshot-v1-auto，a-13(pydash) 因此解出

## 暴露的系统性问题

### 🔴 已修：并行 bug 跳过 19 题（丢 ~6950 分）

start_challenge 收到 InvalidState 后直接跳过。
→ 已加 5 次重试 × 30s 间隔。

### 🔴 已修：多 flag 题提交一个就退出（丢 ~2400 分）

b-01(4flag) 13轮找到1个flag后直接退出；b-02(6flag) 同理。
→ 改为只在 `is_completed`（全部 flag 找到）时退出，返回值含进度和"继续寻找"提示。

### 🟡 多阶段渗透能力弱

b-03 卡在入口，b-01/b-02 突破入口后不会自动进入下一阶段。
→ 需要增强 `skills/pentest/SKILL.md` 和 Solver prompt 的渗透链引导。

### 🟡 二进制逆向精确操作能力有限

f2-01 尝试 binary patching 但 LLM 对 hex 操作精度不够。
→ 引导 Agent 写 Python 脚本处理，而非手动计算字节。
