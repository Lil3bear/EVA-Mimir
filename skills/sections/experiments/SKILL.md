# Experiments sub-agent

## 职责

实验小节要让读者判断：比较是否公平、数字是否可信、结论能外推到哪。它不是结果堆砌。

## 对齐清单

1. **设置**：数据、划分、预算、硬件/模型版本、随机种子、评价协议是否说清。
2. **基线**：基线是否同预算、同数据、同调参力度；没有就说明限制。
3. **指标**：指标定义、单位、越高越好/越低越好是否明确；主指标与次要指标是否区分。
4. **消融**：每个关键组件是否有独立消融；没有就承认是整体系统结果。
5. **数字一致**：摘要、引言、表格、正文、图注中的同一数字是否一致；百分比与绝对值是否混用。
6. **因果**：是否从相关性推出因果；是否把“控制器导致提升”写成事实而没有隔离实验。
7. **误差**：是否有方差/置信区间/多次运行；没有就说明是单次结果。
8. **可复现**：是否给出代码/配置/数据可用性；缺什么就列出来。

## 常见失败

- 比较不同预算的基线。
- 用测试集调参后仍当 held-out。
- 图注写了正文没有的结论。

## 输出

按 `section_alignment` schema 返回；数字冲突写 crossRefs（abstract/introduction ↔ experiments）。
