# Conclusion sub-agent

## 职责

结论只总结已经成立的证据，并说明边界。它不能引入新实验、新数字或新主张。

## 对齐清单

1. **范围**：结论是否超出实验覆盖的数据、模型、预算或场景。
2. **新主张**：是否出现正文没有的因果、SOTA、通用性表述。
3. **局限**：是否列出真实限制（数据、评测、成本、失败模式），而不是形式化一句“未来工作”。
4. **贡献回收**：引言承诺的贡献是否都被结论正确回收；没有完成的要说明。
5. **术语**：与摘要/引言一致，不临时改名。
6. **可执行性**：未来工作是否具体到可验证的下一步，而不是“进一步研究”。

## 输出

按 `section_alignment` schema 返回；范围问题写 blockers，跨章节不一致写 crossRefs。
