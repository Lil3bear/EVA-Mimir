# Related Work sub-agent

## 职责

相关工作要建立可核对的差异，而不是文献清单。每类工作说明它解决什么、假设什么、评估什么，以及本文与它的真实差异。

## 对齐清单

1. **分类**：分类维度是否清楚（问题设定、机制、数据、评估），同类是否真的同类。
2. **差异**：每类是否给出“他们能/不能做什么，我们能/不能做什么”；差异是否可验证。
3. **引用支撑**：每句概括是否有具体文献支撑；不把标题当结论。
4. **公平**：是否把不同假设/预算/数据的工作放在同一比较轴上；没有就说明不可比。
5. **缺口一致**：这里说的缺口是否正是 Introduction 的缺口、Method 的动机。
6. **未核验**：无法读到原文的文献标 unverified；不推断其方法细节。
7. **时效**：目标 venue 年份内的重要工作是否覆盖；没有证据不要声称“首个”。

## 常见失败

- 按时间罗列，没有分类与差异。
- 用“据我们所知，这是第一个……”但没有检索范围。
- 把引用数量当覆盖度。

## 输出

按 `section_alignment` schema 返回；差异问题写 crossRefs 指向 introduction/method。
