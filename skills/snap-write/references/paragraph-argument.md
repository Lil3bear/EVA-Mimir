# 段落论证：五步逻辑链

来源：作者在本工作区提供的段落组织要求。

用于选定段落或短小节的组织与修改，尤其适合 Related Work、综述和方法比较。目标是形成连贯论证，而不是堆砌论文名称，也不是把每段改成五条清单。

## 五个论证环节

1. **定义与范围**：这一段或小节研究什么问题，包含哪些内容，边界在哪里。明确研究对象和讨论层级，避免泛泛背景；自然交代必要范围，不堆砌免责声明。
2. **分类依据**：解决这个问题有哪些主要路线，按什么区别组织这些路线。先说明分类轴，再引出路线；避免将目标、技术和应用场景混成同一层分类。若路线交叉，应如实说明，不强行宣称互斥或穷尽。
3. **方法与机制**：结合代表工作，解释每条路线具体怎么解决问题。写清关键操作、依赖条件及其与问题的关系，而不是逐篇罗列“提出了某方法”。代表工作必须实际支持对应机制，术语沿用领域中准确的含义。
4. **证据与比较**：已有结果证明了什么，不同方法各有什么优势和代价。区分论文报告的发现与作者综合判断；比较应明确任务、数据、指标和预算等适用条件。不同设置下的数值不直接证明优劣，不补造实验、显著性或因果关系。
5. **局限与启示**：还有什么没有解决，由此提炼出什么共同判断。从前述机制和证据推出具体限制、权衡或研究方向，不用空泛的“仍存在挑战”收尾，不无依据地贬低前人或强行导向自己的创新。

## 修改方式

- 先将原文和已核验材料映射到五个环节，识别缺失连接、重复和层级混乱，再局部调整顺序与衔接。保留作者的立场、逻辑和重要限定，不将不同观点改写为虚假的共识。
- 五步是论证检查框架，不是固定五句话、五个标题或五段模板。一个自然段可以融合多个环节；若完整展开需要多段，只在用户授权的小节范围内组织。不要把一段膨胀成完整综述。
- 不要求每个单句或纯方法描述都具备完整五步。已有上下文明确的定义或分类不必重复；根据段落在小节中的作用补齐必要连接。
- 有材料时以材料为依据组织；缺少代表工作、机制或比较证据时，简要指出缺口，或在允许的范围内检索原文。不能为了凑齐结构添加虚构事实、引用、路线或结果。
- 沿用 snap-write 的句式要求：自然的中等长度句子、准确术语和必要连接词，避免长难句、机器人碎句、过度缩短、说明书口吻和防御式写作。
- 默认输出连贯学术段落，不输出内部五步检查表。用户要求诊断时，才另附简短的缺口说明及来源。

## 完成检查

读者能否理解“讨论什么、为何这样分类、各路线如何工作、证据支持哪些比较、由此得到什么判断”？检查每个比较和结论能否回指前文证据；若不能，缩小结论或标记缺口，不用流畅措辞掩盖证据不足。
