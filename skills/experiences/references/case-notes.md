# 通用复盘原则

## 同主机多服务

不要把业务门户视为唯一入口。发现多个服务时，应分别建立指纹、状态和验证结果，避免在单一入口持续消耗轮次。

## 验证码与会话

验证码登录流程应先检查服务端会话或客户端 Cookie 是否已经携带可解码状态，再决定是否投入 OCR。

## Redis 与业务备份

发现 Redis 后应检查所有逻辑数据库和业务键。拿到备份密钥时，还必须形成“密钥、备份位置、解密验证”的闭环，不能只记录其中一步。

## 配置写入的换行语义

配置注入类题目必须区分 CR 与 LF，并验证客户端实际发送的字节与本地实验一致。任何上一轮地址都必须在当前实例重新确认。
