# Crypto 高级攻击速查

> 基础 RSA/AES/XOR 见主 SKILL，这里覆盖进阶题型（LCG、自定义分组密码、背包、带噪、置换群、侧信道）。

## 1. LCG 破解（线性同余）
识别：`seed = (a*seed + c) % m`，题目给连续输出或按比特加密。
```python
# 已知连续输出 x0,x1,x2，求 a,c,m
# m 已知：a = (x1-x2) * inv(x0-x1, m) % m ; c = (x1 - a*x0) % m
# m 未知：用 t_i = x_{i+1}-x_i，m = gcd(t_{i+1}*t_{i-1} - t_i^2, ...) 反复约
```

## 2. 自定义分组密码 → 差分/线性分析
识别：题目给 SPN/S-box/轮函数源码，要求恢复密钥。
- 先跑一轮差分特征，找高概率 S-box 差分对。
- 用 z3 建模 S-box + 轮密钥，直接求解（轮数少时 z3 最省事）：
```python
from z3 import *
key = BitVec('k', 96)
# 约束：encrypt(pt, key) == ct（多组已知明文对）
solve(encrypt(pt1,key)==ct1, encrypt(pt2,key)==ct2)
```
- 轮数多才需要真正的差分/线性，优先 z3。

## 3. 背包密码（Merkle-Hellman / 子集和）
识别：给公钥（超递增序列）和密文（和值），求明文位向量。
- 超递增背包：从大到小贪心（`if c >= w[i]: bit=1; c-=w[i]`）。
- 一般子集和：LLL 格约简求解。

## 4. CRC 带噪 / 少量泄露
识别：服务用 CRC16/32 泄露密钥信息，但结果掺噪。
- 收集多组泄露，把噪声当方程组约束，用 z3 逐位恢复密钥。
- 真值少噪多时，先统计每个值出现频率，取众数再解。

## 5. 置换群上的 DH（对称群离散对数）
识别：题目在 Sn 上做 Diffie-Hellman。
- 把置换分解成不相交轮换，离散对数在轮换上可拆解。
- 逐轮换求解后合并。

## 6. 侧信道（解密只回显坐标/终点/长度）
识别：RSA 解密 oracle 只返回结果的部分信息（如迷宫终点坐标）。
- 用二分/逐位查询，利用 oracle 的单调性恢复明文。
- 或构造多组密文，利用同态性（m*c^e）逐步泄露。

## 通用流程
1. `file`/`strings` 看题目类型，识别是哪种密码。
2. 优先 z3（轮数少/约束明确时最快），不行再上专用算法。
3. 数值/hex 结果用 bash 本地验证后再提交。
