# Venue: Verify the Target, Do Not Import Another Conference's Rules

Independent application adapter informed by paper-pre-submission-review. The vendored upstream guide contains ICLR-specific context; that context is not applicable by default to this application's WWW manuscript. This file owns the app's venue decision process.

## Rule Record

First establish venue, year, track and stage from the project and author. For each rule record the official URL or supplied document, access/version date, exact scope, required versus recommended status, and which source/PDF property was checked. If the target is WWW, inspect that target's actual author instructions rather than starting with ICLR or reusing CVPR's rebuttal practices.

Check what counts toward length, template/submission mode, anonymity, reference and appendix treatment, required statements, supplements and response restrictions. Total PDF pages alone cannot determine main-text compliance when excluded material is allowed.

## Decision States

Use pass only with an applicable rule and checked artifact; fail with a specific contradiction; pending for unavailable or conflicting guidance; not applicable with a reason. A general writing preference, an older kit or a working ACM preamble is not verified current-year policy.

Do not assert a fixed abstract length, introduction length, contribution count, mandatory error bar, confidential chair channel or response experiment permission without an applicable source. Content editing may continue while policy checks remain pending.

Prefer content reduction over hidden formatting tricks. Preserve style files, margins, conference metadata and submission mode unless an authenticated requirement and the author's scope authorize the change. Never invent publication dates, DOI, acceptance status or administrative commitments.
