# Math: Symbols Must Specify an Operation

Independent worksheet augmenting AI-paper-reviewer. Read the operational explanation around an equation, not just its typesetting.

## Symbol and Operation Ledger

For each expression identify the variable's domain, unit or dimension, index set, scope, first definition, update rule and relation to reported metrics. A controller needs initial state, event that increments a counter, reset condition, predicate inputs and decision outcome. A memory field named verified does not define who verifies it.

For a selection predicate inspect quantifiers, ties, empty sets, missing observations, partial completions and failures. State whether scores are continuous, binary or task-specific only when the implementation or protocol supplies that information. A formula comparing two runs does not establish matched budgets or fresh evaluation.

## Boundary Checks

Test the rule symbolically against available definitions: unchanged candidate; one improvement and one regression; equal score but changed completion; absent task; empty admission set. Check whether the stated prose follows from the formula. Do not change a formula or invent thresholds to make it convenient.

Separate undefined notation from a scientifically invalid method. If an equation is clear but the execution protocol is absent, request the missing rule. If prose claims more than the equation establishes, narrow that prose while preserving the equation. A notation correction can close a notation issue, not a missing-experiment issue.

In PDF-only evidence, verify source before calling extraction artifacts mathematical errors. Preserve valid LaTeX, symbol identity, citation and equation labels through all language edits.
