# Review: Objection, Defense, Adjudication

Independent implementation of the application's reviewer workflow, informed by AI-paper-reviewer; response principles also draw on the separately attributed Ding Xiaohan Rebuttal Skill. This is simulated author-facing review, not a conference decision.

## Recover the Paper Before Judging a Paragraph

Read every active section and distinguish inactive appendices. Record the research question, claimed contribution, actual mechanism, decisive result and known limitation. Evaluate the same manuscript version throughout. Do not interpret a stored file, author wish or simulated review as implementation evidence.

Use ten lenses without requiring ten findings: problem relevance; contribution ownership; related-work positioning; method definition; technical correctness; experimental design; comparison fairness; claim/evidence fit; presentation; reproducibility. An absent artifact is a coverage limit, not proof that the work was never performed.

## Mandatory Counterevidence Pass for Material Findings

1. Quote the exact current claim and state why it matters.
2. Search the supplied whole paper for the strongest legitimate answer, including definitions, limitations, captions and protocol details.
3. Check whether that answer concerns the same version, task, information access, budget and denominator.
4. Return supported objection, partial objection, rebutted objection or unresolved evidence gap. Remove rebutted complaints; retain a partial issue only with its remaining scope.

Do not demand a baseline merely because it exists, infer novelty failure from a similar name, count agreeing models as evidence, or convert a style preference into a major flaw. Respect valid defenses even when the user requests a severe review.

## Output and Repair Handoff

For each retained finding provide severity, certainty, exact quote/file, counterevidence and the minimum closure test. Preserve existing issue IDs and merge true duplicates. Distinguish an immediately repairable wording problem from an experiment, code, citation or policy question. Use Rebuttal's worksheet for a response or defensive check, not as permission to change the manuscript during review-only work.
