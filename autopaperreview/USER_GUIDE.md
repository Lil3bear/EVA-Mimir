# 图文操作指南

启动系统后，点击顶部书本图标，或访问 `/guide/index.html`。
图文源文件为 [public/guide/index.html](public/guide/index.html)，包含六张独立
演示项目截图，不含正式论文、密码或模型凭据。

1. 导入 Overleaf Source ZIP，选择主 TeX 文件并编译。
2. 滚动阅读 PDF，选中文字进行翻译、添加修改意见。
3. 核对 Skills 与模型，明确授权后提交修订。
4. 查看执行队列与修订日志。排队成功不代表修改完成。
5. 核对 TeX 差异和新 PDF；失败或未实际解决的批注应保持待处理。
6. 使用版本历史恢复旧稿，或导出 PDF、源码 ZIP 和审稿记录。
7. 可选连接自己的 Overleaf Git，确认无冲突后推送。

团队登录信息由部署管理员私下提供，本公开手册不包含通用用户名密码。
安装、登录生成、模型配置及网络排查见 [安装指南](docs/INSTALL.md)。
