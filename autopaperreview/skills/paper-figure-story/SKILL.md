# Evidence Before Illustration

Independent workflow, informed by [Leey21/awesome-ai-research-writing](https://github.com/Leey21/awesome-ai-research-writing#论文架构图). Accessed 2026-10-19. This is an attributed adaptation, not a redistribution of the repository or a license to reuse its example images.

Read the current abstract, active method, results and captions before changing a figure. Inventory every included asset, including figures in supplementary sections; distinguish inactive source files. For each figure record its purpose, source location, one-sentence takeaway, evidence anchors and intended print width.

Separate motivation (a documented problem) from novelty (the supported change addressing it). Trace every module, arrow, feedback path and result to manuscript evidence. An arrow is a claim: distinguish data flow, control, offline development and evaluation. Do not invent a rejection-feedback loop, automatic skill composition, isolation guarantee or ablation result because it would make a better story.

Before formal method-figure replacement, review the entire current Method and report unresolved scientific issues. A model's 'passed' statement is not proof. Keep designs provisional while relevant author comments, contradictions or implementation gaps remain. Bind approval to the exact manuscript revision; any source update invalidates it. Do not silently resolve author comments.

For an asset edit, preserve the old asset, record the actual model, input revision, Skills hashes, comment text, before/after hashes and compile result. Only move a figure comment to the log after the changed asset has been committed and the paper has compiled. A plan, failed call or identical output is not a completed edit.
